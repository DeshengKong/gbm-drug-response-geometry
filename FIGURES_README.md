# Figures for "Drug-response geometry along the glioblastoma trajectory"

Publication-standard redraws (300 dpi, RGB PNG, 7 in wide) for the Cell Reports
manuscript. Generated by `plot_figures.py` — a single script that runs locally
with the data venv; no Colab needed. Every panel was visually inspected after
rendering (five rounds of layout fixes, the last being the 2026-11-08
pre-submission mock-review round); no label is truncated, no legend
covers data, no annotation overlaps a data point it hides.

## Mock-review revisions (2026-11-08)

The pre-submission mock review (M1–M3, S1–S12, C1–C8) changed all seven
figures. The substantive fixes:
- **M1 — unit of analysis (Figs 1C, 2A):** the pooled ρ values are computed
  over 214 nested quintile rows, not 43 independent comparisons. The panels
  now lead with the comparison-level test (n = 43) and keep the pooled value
  as descriptive. Direction: comparison-level ρ = −0.405, p = 0.0071.
  Amplitude: WITHIN comparisons ρ = 0.064, p = 0.35; ACROSS comparisons
  ρ = +0.396, p = 0.0087 — i.e. amplitude does rise with trajectory
  position between comparisons (consistent with Point 4), and only the
  within-comparison flatness is the Fig 2 headline. The Fig 2 title and
  the manuscript Results were reworded to say so.
- **M3 — Fig 4C is now data-driven:** the six "ratios" in the first draft
  were legend values with no CSV behind them. They turned out to be the
  per-drug pooled centroid DISTANCES from the executed Point 3 notebook
  (not ratios — the label was wrong), and are now deposited as
  `colab_outputs/myeloid_per_drug_centroid_distances.csv` (9 drugs, with
  n_cells and n_units per drug). The panel plots all 9 drugs from that CSV,
  sorted descending, with units in the y-labels; the meaningless 1.0
  reference line is gone.
- **S5 — Fig 7A PC1 sign:** the SVD sign of PC1 is arbitrary; the first
  draft's figure read ρ = −0.979 while the text reported +0.979 (|ρ|). The
  plotting code now orients PC1 to correlate positively with TRAJ, so the
  figure reads +0.979 and agrees with the text.
- **S8 — Fig 3 A2:** the LODO permutation p-value is reported as p < 0.002
  (0/500 permutations), not "p = 0.0".
- **C5 — Fig 5D traceability:** the ρ = 0.158 / p = 0.46 values are now
  deposited as `gse296577/meylan_analysis/meylan_mm2_proxy_patient_test.csv`
  (per-patient proxy dist_diff / frac50_diff for the 8 patients).
- **C1/C2/C3/C4 — annotation placement:** Fig 1E gained an x-axis label
  ("Comparison index (jittered)"); Fig 3C's annotation moved to the
  top-centre so it clears the Low-stratum points; Fig 5B's annotation is
  now two lines at top-right with the panel ylim raised 1.05 → 1.20 so it
  clears the NPC1 VCAN bar (0.762) and the MES-like 2 VEGFA bar (0.922);
  Fig 6C's x-labels now state the section order is not meaningful
  ("Sections (n = 14, unordered)" / "Section (n = 14, file order)").
- **C7 — per-drug n:** units per drug (3–8) are shown in the Fig 2E
  annotation (topotecan 5, ANA-12 3) and in the Fig 4C y-labels.
- **S6 — Fig 1E:** "C reproduced exactly" → "C reproduced".

## Style

- Liberation Sans (Arial-metric-compatible; Helvetica/Arial are not installed
  on this machine). Panel letters bold 11 pt top-left, with a white backing
  box so they read on coloured bars. Panel titles left-aligned 9 pt
  (7.5–8 pt for multi-line stat titles). Axis labels 9 pt, tick labels
  7–8 pt, annotations 7–7.5 pt. Thin black axes (1.0 pt), no top/right spines.
  300 dpi, RGB, 7.0 in wide; heights 6.2–7.8 in by panel count.
- Palette: blue #0F4D92 (main finding), steel blue #3775BA, red #B64342
  (nulls/negatives), teal #42949E, violet #9A4D8E, orange #E8913A
  (composition). Key statistics from each legend are annotated on the panel
  itself (or carried in the panel title where the panel has no empty corner).

## What came from figures4papers (Chen Liu, https://github.com/ChenLiu-1996/figures4papers)

The repo is a collection of matplotlib scripts plus a
`scientific-figure-making/` skill: a minimalist house style (high contrast,
spines off, frameless legends, tight_layout, dpi = 300/600), a semantic
palette, and helper functions (apply_publication_style, create_subplots,
finalize_figure, make_grouped_bar, make_trend, make_heatmap, make_scatter)
plus design-theory notes. It is mostly style/theming; it contains no data
and nothing in it changes any number.

- Applied: the rcParams preset (spines off, frameless legends, tight_layout,
  dpi = 300), the semantic palette (blue_main #0F4D92 as the main-finding
  accent, red_strong #B64342 for nulls/contrasts, neutral grays, teal/violet/
  orange as secondary accents), in-place annotation of key statistics,
  dedicated legend handling (legends below/above the axes, never over data),
  black-edged bars, explicit y-limits, and "consistency over embellishment"
  (one palette, one font, one panel-letter style across all 7 figures).
- Adapted: font sizes scaled down for 7-inch figures (the repo's 15–16 pt is
  for ~14-inch canvases; here panel letters bold 11 pt, titles 9 pt, axis
  labels 9 pt, ticks 7–8 pt, annotations 7–7.5 pt); axes linewidth ~1.0
  (not 2–3); font stack Liberation Sans → DejaVu Sans (Helvetica/Arial are
  not installed on this machine; Liberation Sans is Arial-metric-compatible
  and matplotlib resolves it).
- Rejected: ultra-wide aspect ratios (wrong for a 7-inch journal figure);
  font.size 24; text.usetex = True (LaTeX availability not assumed;
  mathtext is used instead); 3D-sphere/concept helpers and radar plots
  (not needed); hiding x-tick labels in favour of legends (inappropriate
  for data panels). Code was written fresh implementing the conventions,
  not copied verbatim.

## Layout notes (from visual inspection)

- Flat grids (at most 2 panels per row; every sub-panel ≥ 3.3 in wide).
  Nested subgridspec splits that made ~1.6 in sub-panels clipped
  annotations and tick labels and were removed (Figs 1–2 keep a small
  subgridspec only for their full-width E panels, which render fine).
- Single-column panels are only ~2.2 in wide, so right-column titles are
  kept short (≤ ~35 chars at 7.5–8 pt, split over multiple lines where the
  stats must be carried in the title — Fig 3 A2/B2/C2, Fig 7 C2).
- Identity lines stop at 95% of the axis limit so the dash cap never escapes
  the corner.
- Panel letters carry a white backing box so they read on coloured bars.
- DPI metadata is embedded (pHYs, 300 dpi) via a PIL re-save, because
  matplotlib's PNG writer omits it.
